# Mohamed Ilyes Jaouani — Video Editing Portfolio

Your React + TypeScript + Vite + Tailwind portfolio source is included in [`portfolio-source.zip`](./portfolio-source.zip).

## Run locally

1. Download and extract `portfolio-source.zip`.
2. Install Node.js (LTS): https://nodejs.org/
3. In the extracted project folder, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints.

## Publish

The project can be deployed for free using GitHub Pages or Cloudflare Pages. The source archive includes the full site, including `src/App.tsx`, styles, and configuration.

## Personalize

Before publishing, replace the placeholder email `hello@mainframe.co` in `src/App.tsx` with your professional email address.
